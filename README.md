# fr2027-forecaster

Probabilistic forecaster for the 2027 French presidential election (round 1: 18 April 2027, round 2: 2 May 2027).

Polls are the backbone; Polymarket, X trends (via a Grok bot dropping files into `data/raw/grok/`), news and candidate programs are secondary layers that must earn their weight in backtests.

See [SPEC.md](SPEC.md) for the full build spec and milestones.
